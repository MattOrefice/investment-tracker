{# ── Page 9: Methodology ────────────────────────────────────────────────────── #}

Methodology & Data Sources

Style Box Methodology
Size (y-axis): log10(weighted-average market cap in $B), additive-shifted so SPY anchors at y=2.0 (Large/Blend centre). Large/Mid boundary ≈ $79B, Mid/Small boundary ≈ $7.9B at current calibration. Value-growth (x-axis): four-factor z-score — book-to-price, earnings-to-price, dividend yield, cash-flow-to-price — each normalised as fractional deviation from SPY, averaged, then mapped to x with VALUE_SCALE=0.85; SPY/VOO anchors at x=1.0 (Blend centre). Simplification: 4-factor trailing approximation of Morningstar’s proprietary 10-factor score. Treat dot positions as directional indicators of factor tilt, not precise Morningstar equivalents. Universe: US equity ETFs only (VOO, VTV, SPHQ, AVUV).
Fama-French 5-Factor Regression
Per-sleeve decomposition: each equity sleeve is regressed against its own region-appropriate FF5 factor set — US factors (Ken French Data Library) for the US equity sleeve (VOO, VTV, SPHQ, AVUV), Developed ex-US factors for VEA. Avoids model-misspecification from a single full-portfolio regression where non-US and real-asset returns flow into alpha. NW-HAC lags L = floor(4 × (T/100)2/9). Alpha annualized as αdaily × 252. IEMG excluded (no daily EM factor data published by Ken French).
Benchmark Attribution Regression
Model: (Rp − RF) ~ (Rb − RF) + HML + SMB + RMW, where Rb is the daily custom blended SAA benchmark return. The intercept is the active return after controlling for benchmark beta and style tilts — the institutional alpha definition used by PRINCO and JPM IDD. CMA excluded; for a passive/semi-passive implementation it captures ETF-level capex differences rather than a deliberate active tilt. Standard errors: Newey-West HAC.
Time-Weighted Return
Daily-linked chain-linked TWR (GIPS-compliant). For each day t: rt = (Vt − Vt−1 − CFt) / Vt−1. Cash flows assumed at beginning of day. Cumulative return is ∏(1 + rt) − 1.
Benchmarks
S&P 500: SPY total return (adj_close). Custom Blended: SAA target-weight basket of benchmark tickers (SPY, QUAL, IWD, IWM, EFA, EEM, IEF, TIP, 50% VNQ + 50% DBC, BIL), normalized to $1 on inception date.
Brinson-Fachler Attribution
Allocation effect = (wp − wb) × (rb − rb,total). Selection effect = wp × (rp − rb). Portfolio weights = beginning-of-period market value weights. Sum reconciles to active return within 1 basis point.
Drift Status
Flagged “Drift” when absolute drift exceeds the per-sleeve tolerance band (±300 bps for sleeves with ≥10% target weight; ±200 bps for smaller sleeves) or relative drift exceeds 20% of target weight. Both thresholds must be satisfied for “Within” status.
Price Data
Daily adjusted-close from Yahoo Finance, cached in SQLite. Adjusted close reflects splits and dividends (total-return basis). Gaps forward-filled from last trading day. {% if snapshot_captured_at %}Quarter prices locked at {{ snapshot_captured_at }} to prevent retroactive Yahoo Finance adj_close adjustments from shifting historical report numbers.{% endif %}
CAPE (Shiller P/E)
Robert Shiller / Yale (econ.yale.edu). Monthly observations; most recent month shown. Implied 10-year real return: r ≈ −0.070 × ln(CAPE/16) + 0.066.
Macro Data
FRED (St. Louis Fed). T10Y2Y = 10Y−2Y Treasury spread. DFF = Fed Funds Rate. BAMLH0A0HYM2 = ICE BofA HY OAS (available May 2023+).
SAA & Sleeve Targets
Equity 72% / Income 15% / Real Assets 10% / Cash 3%. Ten sleeves with tolerance bands (±2–3%). Full rationale in the SAA section of the application.
